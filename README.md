##  How to Run the Application
Follow these steps to run the application on your local machine:

### 1. Open Project Directory
Open your terminal (Terminal, Command Prompt, or Git Bash) inside the project's root directory (`AI project`).

### 2. Start the Flask Server
Run the following command in your terminal and press **Enter**:
```bash or terminal
python app.py
```
then copy the appeared link and paste it into your browser

## 🕹️ How to Use (Usage Guide)

1. **Select Cities:** Choose your **Start City** and **Goal City** from the dropdown options.
2. **Choose an Algorithm:** Pick one of the 5 available search algorithms from the list (BFS, DFS, UCS, Greedy, or A*).
3. **Find Route:** Click the **Find Route** button to calculate the path. The app will render the path on the map canvas and display the total distance cost (in km) along with the number of steps expanded.
4. **Compare All:** Click the **Compare All** button to run all 5 algorithms simultaneously for the selected cities and view a clear comparison table showing paths, costs, steps, and optimality.
